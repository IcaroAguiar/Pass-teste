# Pass-Teste

Teste de seleção para desenvolvedor Full-stack na empresa Pass.

## Stack Tecnológica

Este projeto utiliza uma stack tecnológica padronizada conforme definido na constituição do projeto:

- **Linguagem**: TypeScript
- **Framework**: Next.js
- **Backend**: Next.js API Routes (backend autoarmazenado na aplicação)
- **Banco de Dados**: SQLite (arquivo versionado no projeto)
- **Tipagem**: TypeScript de ponta a ponta (tipos de requisição/resposta, modelos de dados)

## Política de Versionamento

Este repositório versiona **APENAS** artefatos relacionados à construção do produto. Artefatos de planejamento, assistentes de IA e ferramentas de desenvolvimento **NÃO** são versionados e são mantidos apenas localmente.

Diretórios/arquivos não versionados:
- `.cursor/`
- `.specify/`
- `specs/`

Consulte `.specify/memory/constitution.md` para mais detalhes sobre os princípios do projeto.
